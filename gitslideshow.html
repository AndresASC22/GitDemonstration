🤔 What are Git and GitHub?

Git (The Tool)

  • Version Control System
  • Runs on your computer
  • Tracks file changes
  • Creates "snapshots" (commits)
  • Works offline
# Git is local
git init
git add file.py
git commit -m "message"

GitHub (The Platform)

  • Cloud hosting for Git repos
  • Collaboration features
  • Web-based interface
  • Social coding platform
  • Project management tools
# Connect to GitHub
git remote add origin url
git push -u origin main

🔑 Key Concepts

Repository (Repo)

A project folder tracked by Git

git init # Create new repo
git clone url # Copy existing repo

Commit

A snapshot of your changes

git add .
git commit -m "description"

Branch

Independent line of development

git branch feature
git checkout feature

Merge

Combine changes from branches

git merge feature
# Resolve conflicts if any

💻 Essential Git Commands

Command Description Example
git init Initialize a repository git init my-project
git status Check current state git status
git add Stage changes git add .
git commit Save changes git commit -m "message"
git log View history git log --oneline
git branch List branches git branch feature
git checkout Switch branches git checkout main
git merge Combine branches git merge feature
📝 Remember:   Commit often, with clear messages!

☁️ GitHub Remote Commands

Connect to GitHub

git remote add origin https://github.com/username/repo.git
git remote -v # Verify connection

Push & Pull

git push origin main # Upload
git pull origin main # Download
git clone url # Copy entire repo

Typical GitHub Workflow

  • git clone https://github.com/user/repo.git
  • git checkout -b new-feature
  • git add .
  • git commit -m "Add new feature"
  • git push origin new-feature
  • # Create Pull Request on GitHub

🔄 Pull Requests (PRs)

The heart of GitHub collaboration!

What is a PR?

  • Request to merge changes
  • Code review platform
  • Discussion thread
  • Automated testing
  • Documentation of changes

PR Workflow

  1. Create branch
  2. Make changes
  3. Push to GitHub
  4. Open Pull Request
  5. Review & discuss
  6. Merge
# Create PR from command line
gh pr create --title "My feature" --body "Description"
# Or create on github.com

✨ Git & GitHub Best Practices

Commit Messages

  • Clear and descriptive
  • Present tense ("Add feature" not "Added")
  • Brief summary (50 chars)
  • Reference issues (#123)

Branching Strategy

  • main = stable code
  • feature branches for work
  • develop branch for integration
  • Delete merged branches

Repository Health

  • Good README.md
  • .gitignore file
  • License file
  • Contributing guidelines

Security

  • Never commit secrets
  • Use .gitignore
  • 2FA on GitHub
  • Review access permissions
